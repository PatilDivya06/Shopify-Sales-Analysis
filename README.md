# 📊 Shopify Sales Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI Sales Dashboard** developed using Shopify sales data. The dashboard provides insights into revenue, order trends, customer behavior, and product performance, helping businesses make data-driven decisions.

---

## 🎯 Business Objective

The objective of this project is to analyze Shopify sales data to:

- Monitor revenue performance
- Track customer purchasing behavior
- Identify top-performing product categories
- Measure Average Order Value (AOV)
- Analyze sales trends over time
- Support business decision-making through interactive dashboards

---

## 🛠️ Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel
- Data Modeling
- Data Visualization

---

## 📂 Dashboard Features

- 📈 Total Revenue
- 🛒 Total Orders
- 💰 Average Order Value (AOV)
- 👥 Customer Analysis
- 📅 Revenue Trend (Year, Quarter, Month & Day)
- 📦 Product Type Performance
- 📊 Revenue Growth %
- 📍 Interactive Filters & Slicers
